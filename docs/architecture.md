# Архитектура и эксплуатация

## Слои

`backend/app/analytics` читает parquet, проверяет согласованность, строит направленный NetworkX-граф со всеми nodes, вычисляет признаки, роли, приоритет и объяснения. Конфигурация — `config.json` рядом с pipeline. Выгрузки предназначены для проверки и передачи аналитикам.

`backend/app/api` определяет Pydantic-контракты и хранилище готового снимка. Первоначальный расчёт выполняется при запуске. Запросы используют уже рассчитанные словари и индексы по gid. Фоновый пересчёт создаёт новый результат; только успешно проверенный снимок заменяет текущий. При ошибке предыдущий снимок остаётся доступен. Задачи живут в одном процессе: для MVP следует запускать один Uvicorn worker.

`backend/app/agent` содержит разрешённые инструменты, типизированные параметры, распознавание русских намерений и шаблоны ответа. Инструменты используют снимок API; сеть, shell, SQL и произвольный Python им недоступны. Ответ отделяет наблюдение от гипотезы, перечисляет инструменты и даёт ссылки на сущности. Внешняя LLM не реализована: этот необязательный режим не нужен для основных сценариев.

`frontend` — React/TypeScript/Vite, React Router, TanStack Query и Table, Recharts, Cytoscape, Lucide; собственные CSS-компоненты. В development Vite проксирует `/api` на сервер; после сборки FastAPI отдаёт SPA с того же адреса. Шрифты и графика не требуют внешних сервисов.

Клиентские gid в исходном наборе превышают `Number.MAX_SAFE_INTEGER`. Python хранит их целыми без потери точности, а JSON API сериализует gid, src/dst и ссылки на клиентов десятичными строками. Frontend никогда не преобразует их в JavaScript Number. Номера кластеров остаются обычными числами. При открытии CSV в Excel следует импортировать столбцы gid как текст, чтобы Excel также не округлял идентификаторы.

## Границы объёма

Список клиентов выдаётся страницами. Граф по умолчанию ограничен приоритетными узлами, сообществами или ego-сетью, а не всеми 2 248 клиентами. Направленные рёбра сохраняются при отображении. Свернутый граф кластеров агрегирует межкластерные суммы без дублирования.

Нет БД, очереди заданий, регистрации пользователей и внешнего хранения. По умолчанию приложение слушает loopback; это инструмент для доверенной локальной среды. Docker также публикует порт только на 127.0.0.1. Файлы изменяются локально, загрузка через интернет не требуется.

## Работа с источником

Все три parquet автоматически используются, если присутствуют. Отсутствие всего набора включает помеченную синтетическую демонстрацию. Частичный набор и повреждённый parquet вызывают понятную ошибку; реальные данные никогда не заменяются демонстрационными для маскировки ошибки. Дубли gid и агрегированных пар недопустимы. Совпадающие строки операций сохраняются с предупреждением: без ID операции нельзя доказать дублирование.

## Приватность

gid — единственный идентификатор клиента. ФИО, ИИН, доходы и назначения не создаются. CORS ограничен локальным UI. Секреты не требуются; `.env.example` описывает пути. Каталог исходных данных не отдаётся через web. Экспорт разрешён только для трёх известных CSV.
