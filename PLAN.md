# План и приёмка

1. Аудит архивов, стартового кода и схем. Сохранить исходные данные и описание.
2. Подготовить спецификацию, контракт API и изолированные модули аналитики, API, UI.
3. Реализовать воспроизводимый pipeline и проверить роли на контролируемых графах; выгрузить все реальные узлы.
4. Реализовать API с атомарным обновлением кэша и безопасными инструментами локального Copilot.
5. Подключить все экраны интерфейса к API, progressive disclosure графа, фильтры и переходы.
6. Проверить CSV, детерминированность, ограничение depth=4, семантику времени и seed, API, пересчёт и полный пользовательский путь.
7. Выполнить Python/frontend lint, typecheck, production build, аудит зависимостей и визуальную проверку браузера.
8. Проверить запуск одной командой и отдельный pipeline, записать фактические измерения и демонстрационный сценарий.

Приёмка считается пройденной только по фактически выполненным проверкам. Финальный статус и ограничения — в `STATUS.md`.

Все этапы локального Windows MVP завершены. Реальные parquet обработаны, UI проверен в браузере, запуск одной командой выполнен. Docker и Unix подготовлены, но не исполнялись в текущей среде; это отражено в STATUS и README.
